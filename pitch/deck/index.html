Para quien presenta

Es la lámina que saca al jurado de «una red neuronal que predice». La red no aprende un dataset: aprende, para toda la familia de datasets que el modelo generativo puede producir, el posterior de los parámetros dado el dataset (NPE, inferencia basada en simulación, amortizada). Por eso un archivo nuevo no exige entrenar nada. La comparación con un LLM es una analogía (se entrena antes, una vez; después solo se usa): Krylov no es un modelo de lenguaje, y en la app el modelo de lenguaje solo propone el calce de columnas y redacta. Es la respuesta para quien no quiere ver gráficos de convergencia: un número de 0 a 1. Mide una sola cosa: cuando Krylov dice «entre tanto y tanto» (rango de 90%), ¿la respuesta cayó adentro?
